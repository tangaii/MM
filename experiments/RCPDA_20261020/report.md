# RCPDA_20261020 正式实验报告

状态：complete；正式任务 60/60；科研判断：**NO-GO**。

## 研究动机与问题边界

原始 D4 用年龄×性别条件化疾病原型对影像分支表示做训练期辅助监督。本轮检验两个可靠性问题：条件原型是否在互斥站点半区上比全局类别原型有更低的类别均衡风险，以及影像原型梯度是否与最终多模态分类 CE 的影像表示梯度相容。门控只调节原始 D4 的逐样本辅助 CE。
既有历史发现显示，原始 D4 与重复实验受随机轨迹影响；同方向原型不能单独说明条件原型更有判别力。RCPDA 不预设 F4 最优，也不以测试集选择模型、阈值或超参数。
论文方法与本地根源码核对：[MM-GTUNets 论文](https://arxiv.org/html/2406.14455v3)，[指定 GitHub 仓库](https://github.com/tangaii/MM)。本地仓库版本另保留了已记录的 PPU 兼容实现；本轮不改根模型。

## 原始模型接入、复现协议与历史锚点

调用链为原始 RFE 影像特征及真实非影像输入 → Imaging GTUNet → Non-imaging GTUNet → 原 Multi-modal Attention → 原 Classifier → 原生 CE + Graph Loss。通过 `img_unet` forward hook 取得 `z_img=[871,16]`。辅助目标只从该次影像输出接收梯度；无新增可训练参数，验证和测试不调用辅助模块。
只读复用 DRPA_20261014 的 seed 911 十折 `splits.pt`、`train_start.pt`、selected features、RFE 支持索引、VAE、完整 RNG 与 fingerprints。保持 ASD=0、TD=1，Adam lr=1e-4、weight decay=5e-4、最多500 epoch、patience=100、原训练/验证 CE+Graph、严格下降选模规则和随机前向行为。每 epoch 一次训练 forward、一次验证 forward；测试恢复 best checkpoint 后使用训练结束 RNG，以 grad-enabled 模式执行一次 forward。
历史限制继续保留：RFE 使用原历史预处理、人口图为871节点传导式图，VAE随机采样，eval 路径仍有随机性；同站点十折不证明未见站点泛化。

## 九个预定科学问题的直接回答

1. **F4 是否同时改善 ACC 和 AUC？** F4 相对本轮新鲜 F1 的 ACC/AUC 配对均差为 -0.229pp/-0.653pp；因此 没有同时改善。
2. **SEN 与 SPE 的权衡？** F4-F1 的 SEN-ASD 为 +0.750pp，SPE-TD 为 -1.073pp；阈值附近的类别变化与排序指标必须分开解读。
3. **F4 是否优于两个单因素？** 相对 F2 的 ACC/AUC 为 +0.000pp/+0.117pp，相对 F3 为 -0.114pp/+0.080pp；没有形成两项指标都一致的组合优势。
4. **F4 是否超过原生 F0？** F4-F0 的 ACC/AUC 为 +0.340pp/-0.048pp；SEN/SPE 为 +0.970pp/-0.217pp，不能只用 ACC 判断。
5. **真实表型是否优于 F5 打乱对照？** F4-F5 的 ACC/AUC 为 +0.000pp/+0.006pp；十折打乱条件改变比例均值为 98.95%，每折均发生改变，因此不能把接近结果归因于打乱未生效。
6. **门控是否实际激活？** F4 站点门控均值/非零折内比例为 0.1364/0.2955，梯度门控为 0.5882/0.7832，组合门控为 0.0808/0.2319；两种门控都实际激活，但组合门控只在约 23.2% 样本上为正。
7. **是否只是阈值附近改善而没有概率排序改善？** F4-F1 的 AUC 为 -0.653pp，所以 ACC 与 AUC 的符号必须共同考虑；本轮不能把阈值指标变化单独解释为排序改善。
8. **哪些结论可能来自随机性？** 历史 D4/E4 复现审计显示 PPU 长轨迹、随机验证前向、best-checkpoint 选择和一次随机测试前向都可能放大亚百分点差异；本轮只有 seed 911，故微小差异不能视为稳定因果效应。
9. **一个 seed 的限制？** 十折来自同一 seed 且折间相关，不能代表多 seed 稳定性；仍保留跨折监督 RFE、871 节点转导图、VAE/eval 随机性和同站点交叉验证限制，不能宣称跨站点泛化或临床部署。

## 公式与诊断口径

原始 D4 只用 outer-train：固定三个私有子折，每个 query 的参考池排除自身整个子折。年龄 kernel 为 exp(-0.5*((age_i-age_j)/h)^2)，h=max(2,train-IQR/2)；性别同/异/未知权重为1/0.5/0.75。当前 detach teacher 按训练均值与总体 SD 标准化，SD 下限0.05，tau 为训练标准化 teacher 的平均平方中心距离，下限1。每类 ESS=(sum(w))^2/sum(w^2)，共同 beta=clip((min_class_ESS-8)/32,0,1)；条件原型=beta*条件加权均值+(1-beta)*全局类均值。参考池无任一类别则屏蔽该 query。逐人辅助 CE 来自 -||query-prototype||^2/tau，仅当前 query 接收梯度。

跨站点门控在同一参考池的完整互斥站点 A/B 上：只用 A 的 teacher 构造条件/全局原型，在 B 上用 query 的 kernel 做两类各0.5权重的 CE 风险，反向 B→A 同理；构造及评估的每类有效权重均需 ESS>=2。gain_AB=R_global(A→B)-R_conditional(A→B)，gain_BA 同理；r_site=max(0,min(gain_AB,gain_BA))/max(abs(gain_AB),abs(gain_BA),1e-6)，缺失支持时为0。实际 D4 辅助 CE 仍使用完整参考池原型，不替换为半区原型。

融合梯度门控：g_cls=grad_z(原始融合分类CE)，g_proto=grad_z(未门控D4)，按完全相同 outer-train 顺序取每人梯度；r_grad=clip(dot(g_cls,g_proto)/max(norm(g_cls)*norm(g_proto),1e-12),0,1)，任一范数<=1e-12则为0。所有门控 detach；F2用r_site，F3用r_grad，F4/F5用二者乘积。辅助损失=sum(valid*r*CE)/max(sum(valid),1)，保持固定分母。lambda=clip(0.05*norm(grad_z(native))/(norm(grad_z(D4))+1e-12),0,0.5)*min(epoch/9,1)，始终从未门控 D4 计算。

门控表的均值与非零比例先按每个训练 epoch 的 outer-train 样本计算，再对 epoch>=9 的记录汇总，因此训练较长的折权重较大；不是测试评价指标。影像参数梯度比只在预定采样 epoch 统计。JSON 中 gate 分布自身的 nonzero_fraction 表示“epoch 均值非零比例”，样本级比例应读取相邻 *_nonzero_fraction 字段的 mean。F1 的未门控参考 z 梯度比例为0.05，没有新门控。F4 实际门控后比例约0.01066，不做门控后重新补偿放大。
