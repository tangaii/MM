# 实验21：PCDPA-X2

## 研究问题与方法

保持实验20 M3 的双分支原型 CE、学生 q_ph、0.25 KL 系数、两条分支各自 5% 梯度预算和原生训练/验证/测试协议。本实验唯一改变 KL 教师目标：N1 为同 D4 私有折其他训练者的类别先验，N2 为其影像 D4 概率均值，N3 为年龄与性别核加权的影像概率，N4 为使用历史同站点联合置换年龄/性别的负对照。教师仅在 outer-train 内构造，参考不含自身且只取同私有折；空参考行在四组共用有效掩码下跳过。

年龄/性别只调整影像教师概率的聚合权重。影像教师、真实非影像 D4 CE、学生 logits、gamma、原型和梯度预算在四组定义中相同。教师概率 detach；KL 方向为 KL(T || softmax(q_ph))。训练中只捕获原生两条 GTUNet 输出，不增加参数或模型 forward。

## 审计偏差与科研判断

最终执行状态为 **COMPLETE_WITH_DEVIATION**；正式训练本身为 40/40 完成。冻结的 `analyze.py` 在配对均值字段上存在内部接口不一致：首次分析触发 `KeyError`，兼容后又触发格式化类型错误。没有修改冻结源码或 manifest；使用一次性内存数值适配器重新执行了完整分析、报告和摘要，并独立复核 40/40 个 artifact。该分析器偏差已写入 `summary.json` 与 `audit.json`。

并发运行日志发现 450 个 NUL 填充字节；仅在新实验目录内移除这些字节后，362 行均可解析为 JSON。逐任务 JSONL 未发现 NUL，任务结果不受影响。无训练失败、无重试、无补训。

N3 的教师目标确实区别于 N2/N4，但条件加权没有显示额外诊断信息：N3 outer-train 教师准确率为 50.88%，低于打乱对照 N4 的 51.60%；N3 教师熵为 0.69185，平均跨患者概率标准差为 0.01694。N3 非影像学生训练准确率为 50.23%、熵为 0.69255，真实条件 ph 原型 CE 从 0.6936 变为 0.6942，仍接近均匀预测。N3 KL 从 0.00056 升至 0.00374；KL 对 phenotype embedding 有非零梯度（范数均值 0.00181），对 image embedding 的直接梯度为零，CE/KL 梯度余弦均值 0.0325。KL 路径存在，但没有带来有用的学生学习或 AUC 收益。

科研判断为 **MIXED，不建议进入 MICCAI 2027 第一创新点候选**。N3 AUC 相对历史 M3 仅高 0.00021 pp，低于 N1/N2/N4/D4；N3−N2、N3−N4 的 AUC leave-one-fold-out 方向均会改变。相对历史 M3，N3 ACC 低 0.114 pp、SPE 低 0.435 pp、SEN 高 0.250 pp。实验没有预先定义“明显回退”的数值界限，因此不把这些小差值重新解释为通过门槛。
