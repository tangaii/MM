# D4_REPRO_AUDIT_20261020：D0/D4 与 E0/E1 复现漂移审计

状态：**完成**。只读核查了历史PCDCA_20261019的D0/D4与SCPDA_20261020的E0/E1，未重新训练任何正式fold。

## 目标与方法

定位历史D0→E0和D4→E1的seed 911、10-fold结果漂移。核查40份完整fold结果及SHA、20对fold的患者ID/索引/标签、输入与配对指纹、RFE/初始化/VAE/RNG锚点、optimizer参数顺序、原型设置、训练日志、Checkpoint及正式测试RNG；GPU上执行84次交叉Checkpoint×RNG推理、60次固定测试随机状态推理、fold2验证集固定RNG前向10次，以及3步×3重复的计数hook开关对照。没有重拟合RFE/VAE，也没有改变模型随机性或历史评估协议。

## 结果与结论

|比较|历史→新运行|ΔACC|Δprob-AUC|
|---|---:|---:|---:|
|D0→E0|82.1042→82.4464% / 88.1012→88.4182%|+0.3422pp|+0.3170pp|
|D4→E1|82.5588→81.8717% / 88.6897→88.1644%|-0.6870pp|-0.5253pp|

未发现原始模型源码、输入、划分、训练目标、优化器参数顺序、选模规则或E1算法开关不一致。代码SHA逐文件一致，E1关闭EMA及类别独立ESS。40/40结果哈希和独立指标复算通过，全部20对输入/训练起点指纹一致。

最有力的解释是PPU原生训练轨迹的非逐位可重复，加上随机验证前向影响Checkpoint选择，并在部分fold叠加随机测试前向。原因并非一个已被隔离的单一算子。实验12既有同一原始函数、相同初始化/VAE/RNG、无hook/额外反向的3次复跑，ACC范围达5.68pp；因此轨迹差异不是本轮计数hook特有。D4/E1 fold0同旧测试RNG时Checkpoint变化已造成ACC−2.27pp；fold2同时出现best epoch 175→152、best validation loss 0.713966→0.727794和测试RNG变化，正式ACC/AUC分别−4.60/−4.51pp。交叉四格确认fold2测试RNG本身亦改变AUC约−3.66pp，并存在交互。

五次固定RNG下，同一Checkpoint的测试ACC范围最高5.75pp、AUC范围最高5.41pp，远大于D4历史相对D0仅+0.45pp ACC、+0.59pp AUC的表观差。fold2固定RNG验证的随机loss范围约0.064–0.069，大于正式best loss差0.0138；这是post-selection敏感性诊断，不是无偏重评。序列化恢复错误基本排除：A/D重放复现正式logits，误差不超过约9.3e-6。短程强制确定性等价检查通过；确切产生长程漂移的PPU算子与历史PyG/驱动版本仍未确认。计数hook差异在短程重复噪声量级，未显示其为主因。

## 后续建议与限制

不修改根模型代码，也不把D4称为无效或已被稳定证明有效：其小幅历史增益低于目前观察到的PPU训练/推理随机变化量级。后续对小于1pp的增益，应固定物理卡与负载、记录PyTorch/PyG/PPU驱动及backend flags、保存每epoch验证前后完整RNG与Checkpoint状态，并使用多个配对seed和同源复跑。原生历史协议与任何确定性诊断协议必须分开报告。历史转导人口图、RFE泄漏及eval随机前向等限制仍在。
